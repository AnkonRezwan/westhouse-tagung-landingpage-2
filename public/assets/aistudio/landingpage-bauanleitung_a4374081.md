# Build a new Westhouse Augsburg landing page

Read landingpage-texte.md as the German copy source. Build a brand-new standalone landing page from scratch in this project, with a new layout and components. Use the existing website as a reference for the brand, verified offer details and approved photography. Create the new page in preview first. For production, the recommended path is /tagen-in-augsburg/ on westhouse-augsburg.de. Switch that path to the new page only after approval. Keep all visitor-facing text, form labels and messages in German.

## 1. Set up the page

- Create a responsive landing page for businesses planning conferences, seminars and congresses in Augsburg.
- Use the SEO title and meta description from the copy file as metadata. Use one H1 and follow the H2/H3 hierarchy from the copy file.
- Apply Westhouse brand assets where available. Use approved venue photography and descriptive alt text for meaningful images.
- Check the page at mobile and desktop widths before continuing.

## 2. Build the hero, room overview and hotel section

- Build the hero with its headline, lead paragraph, facts row and two buttons. Link “Tagung anfragen” to #anfrage and “Räume und Kapazitäten ansehen” to #raeume.
- Implement the capacity table as HTML with column headers. Ensure all values are readable on mobile. Link to the room overview, seminar rooms and Anna Maria hall.
- Add the hotel section and link to the existing /tagungshotel/ page. Present Westhouse as the venue provider and Hotel einsmehr as the hotel partner.
- Before publication, confirm seating capacities and resolve the existing 480 versus 500 discrepancy with the venue team. Confirm the group room booking process with the hotel partner.

## 3. Build packages, event reference and arrival information

- Add both package examples and the catering and technology section. Link to the approved conference brochure when available.
- Add an event reference once the client approves a real case with the event format, attendee count, rooms used and a photo or attributed quote.
- Add the arrival and parking section. Confirm the visitor address, transit stop, map link, parking charges and accessibility details before publishing. The current website and tourism directory list different street numbers.

## 4. Build the FAQ

- Copy the eight German questions and answers from the copy file. Use the supplied H2 section heading and an H3 for each question.
- Render all answers as HTML text on initial load. An accordion may collapse them visually if its controls support keyboard interaction, visible focus and accessible expanded states.
- Check that answers about seating, hotel rooms and parking agree with the main page content. Add prices or booking terms once approved. FAQ schema is optional and unnecessary for this build.

## 5. Build and test the inquiry flow

- Add the form at #anfrage. Collect name, company or organization, email, event date or date range, estimated attendance and event type. Offer optional fields for catering, technology, hotel needs and notes. Confirm whether the sales team needs a phone number.
- Connect submissions to the approved recipient or CRM. Show German field errors and a German success message. Record one lead event per confirmed submission if the project has an analytics integration.
- Test both hero buttons, form validation, mobile usability, successful submission, delivery and lead-event deduplication. Keep delivery pending until an approved endpoint is available.

## 6. Review and prepare launch

- Provide the preview URL, completed sections, test results and outstanding approvals.
- For launch at the recommended path, verify HTTP 200, a self-referencing canonical, production indexability, sitemap inclusion and incoming internal links. Review query-to-page performance in Search Console after rollout.
